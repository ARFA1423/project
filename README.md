💰 Expentia – Personal Finance Management System

Expentia is a personal finance management application developed as an academic mini-project. It helps users manage financial activities through a web-based interface, with features for tracking transactions, managing accounts, viewing balances, and accessing financial insights.

🚀 Features

- User Authentication: User registration and login.
- Account Management: Manage financial accounts.
- Transaction Management: View and manage financial transactions.
- Balance Tracking: Check account balances.
- Categories: Organize financial activities into categories.
- Currency Exchange: Access the currency exchange section.
- Financial Dashboard: View financial information through a dashboard.
- Financial Insights: Access insights and statistics.
- Password Management: Forgot-password and password-reset pages.

🛠️ Technologies Used

- Backend: Python
- Backend Server: Uvicorn
- Database: SQLite
- Frontend: HTML, CSS, JavaScript
- Charts: JavaScript chart functionality
- Containerization: Docker Compose
- Testing: Pytest

⚙️ Installation and Setup

1. Clone the Repository

git clone https://github.com/ARFA1423/project.git

2. Navigate to the Project Directory

cd project

3. Create a Virtual Environment

python -m venv venv

4. Activate the Virtual Environment

Windows:

venv\Scripts\activate

5. Install Dependencies

pip install -r requirements.txt

6. Run the Application

python run.py

7. Open in Browser

http://127.0.0.1:8001

🎯 Project Objective

The main objective of Expentia is to provide a centralized web-based platform for managing personal financial activities. It aims to make financial tracking easier through account management, transaction monitoring, balance checking, and financial insights.
